# Prompt Engineering for RAG
Effective RAG prompts instruct the model to use only provided context, cite sources, and say "I don't know" when unsupported.
Include clear role, question, numbered context passages, and output format. Few-shot examples stabilize style.
Long contexts need prioritization: put critical evidence near the question or use reranking.
Temperature and max tokens affect faithfulness vs creativity — prefer low temperature for factual QA.
