# Neural Networks Basics
A feedforward network stacks linear transforms and nonlinear activations (ReLU, GELU, sigmoid). Depth and width control capacity.
Loss + optimizer + regularization define training. Batch normalization and residual connections stabilize deep nets.
CNNs exploit spatial locality for images; RNNs/Transformers handle sequences.
Universal approximation says wide shallow nets can approximate continuous functions, but deep nets learn hierarchical features more efficiently.
