# Hypothesis Testing
Null hypothesis H0 states no effect; alternative HA states an effect. p-value is P(data as extreme | H0).
Type I error (false positive) rate is α; Type II (false negative) relates to power. Multiple testing needs correction (Bonferroni, FDR).
t-tests, chi-square, ANOVA, and Wilcoxon cover common designs. Check assumptions (normality, independence).
Statistical significance ≠ practical significance — report effect sizes and confidence intervals.
